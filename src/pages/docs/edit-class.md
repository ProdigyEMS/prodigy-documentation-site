## Edit Class
To access the class edit feature, click **Manage** under the **Classes** menu. Choose **Organization Class** and click on the published class you want to edit.
{%figure src="/images/edit_class.png" alt="Published class page showing the Edit options for each section" /%}
Clicking on the **Edit** option in the top sections will open up the same editor you used to build the class initially. You can make any updates here that can be made during the class creation. For information on these different options, please review the [Create a Class](/docs/create-class)
## Administrative Documents
{%figure src="/images/admin-docs.png" alt="Administrative Documents section on the class page" /%}
This section allows you to add documents that can only be viewed by system administrators and training officers. This is a great spot to save physical rosters, original PowerPoints, class objectives, or CE documentation. Click on **Edit Administrative Documents** to get started.
{%figure src="/images/admin-docs.png" alt="Edit Administrative Documents view listing uploaded documents" /%}
From here, you will be able add, delete, or review documents that have been added. Click **Add Document** to upload a document.
{%figure src="/images/add-admin-doc.png" alt="Add Document dialog for uploading an administrative document" /%}
You can upload a document and we will use the documents name as the name on Prodigy. Optionally, you can give the document a different name when uploading.
## Class Quiz
Clicking on **Edit Quiz** will bring up the standard quiz editor from the class builder. You will also see basic statistics about the class quiz here as well.
{%figure src="/images/edit-quiz-stats.png" alt="Class Quiz section showing the Edit Quiz option and quiz statistics" /%}

## Adding a Class to a System Training Plan
Prodigy system recertification plans, such as NREMT - Paramedic or a state plan, come with their own requirement groups and categories. You can attach a class your department built, or any class available to your organization, to one of those categories. Once the class is attached, completing it counts toward that category's required hours for any clinician assigned that plan. This is done from the class page rather than from the [Training Plan Builder](/docs/training-plan-builder).

{% callout title="Credit Your Own Classes Toward System Plans" %}
Attaching a class to a plan category is how a department's own class gets credited toward a system recertification plan. You do not need to rebuild a custom plan to cover it.
{% /callout %}

### System Training Plan Card
Open the class you want to attach the same way you would to edit it. Below the class overview and bibliography you will find the **System Training Plan** card.
{%figure src="/images/system-training-plan-card.png" alt="System Training Plan card on the class page showing an existing plan row and the Add to Training Plan action" /%}
The card lists every plan and category the class is already attached to. Each row shows the plan name along with a tag for the group and category, for example **NREMT - Paramedic** with the tag **National › Adult Cardiology**. Each row has a **Remove** action that detaches the class from that plan category.

### Add Class to Training Plan
Click **Add to Training Plan** in the top right of the card. This opens the **Add Class to Training Plan** page, where you will choose the system training plan and category where this class should appear.
{%figure src="/images/add-class-to-training-plan-form.png" alt="Add Class to Training Plan page with the Training Plan and Category fields" /%}
- **Training Plan** - A searchable dropdown listing every available system plan. Entries show the plan name, the certification level, and a state abbreviation where the plan is state specific, for example **NREMT - Paramedic — Paramedic** or **Arizona EMT — EMT · AZ**. Type in the search box to filter the list.
- **Category** - Stays disabled until a training plan is chosen. Once a plan is selected, the dropdown lists that plan's categories grouped by requirement group. Categories the class is already attached to do not appear in the list.

For example, choosing NREMT - Paramedic shows a **NATIONAL** heading with Adult Airway, Adult Medical, Adult Trauma, Operations, Pediatric Airway, Pediatric Cardiology, Pediatric Medical, and Pediatric Trauma beneath it.

Click **Add to Training Plan** to save. If you click **Cancel** after selecting a plan or category, a **Changes will be lost** confirmation appears before your selection is discarded.

A class can belong to more than one plan and more than one category. Repeat the process for each plan or category you want the class to count toward, and each one appears as its own row on the System Training Plan card with its own **Remove** action.

{% callout type="warning" title="Adding Classes to System Plans" %}
Remember, adding a class to a plan affects clinicians already in progress. The new class may change the completion percentage for a clinician who has already started that plan.
{% /callout %}
